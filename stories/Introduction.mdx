## トークンの単一ソースは `theme.css`

トークンはこのリポジトリの `theme.css` の `@theme` が単一ソースで、CSS 変数として出力されます。
消費側は `@insession/design-system/styles.css` を1枚読むだけで、Tailwind は要りません。

生値（マジックナンバー）や生 `#hex` / `rgba()` は書かず、足りなければ `theme.css` にトークンを足します。

### ⚠ トークン名と実際の色がずれているものがある

パレット刷新の際、**トークン名は互換のため据え置いたまま値だけ振り替えた**ものがあります。
名前から色を推測しないでください。

## ライト / ダーク

`theme.css` が**両方のトーンを持ちます**（1.5.0 で消費側に重複していたライト値をここへ一本化）。
ダークが既定で、ライトは `<html data-theme="light">` のときだけ効きます。

このカタログでは**ツールバーの Theme トグル**で切り替えて見比べられます（消費側と同じやり方で
`html` の `data-theme` を書き換えている）。なお外枠（サイドバー / ツールバー）は DS のダークトーンに
固定してあるので、トグルで変わるのはストーリーの描画領域だけです。

## v2 以降は Base UI ベース

Popover / Menu / Modal / ConfirmModal / Tabs は [Base UI](https://base-ui.com/) ベースの
compound API（`Popover.Root` / `Trigger` / `Portal` / `Positioner` / `Popup` …）です。
落とし穴（Menu パートを `Popover.Popup` の中に置けない、PiP へ出すなら `container` を明示する等）は
リポジトリの `README.md` に集約しています。
